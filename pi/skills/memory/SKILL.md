# Memory

Long-term memory is the file `../pi/MEMORY.md` (relative to your working directory).

- Read it at the start of any task where past context could matter.
- When the owner tells you something worth keeping (a preference, a fact, a decision), add one short bullet under a fitting heading.
- Update or delete bullets that become outdated. Don't duplicate them.
- Never store secrets (passwords, keys, tokens).
